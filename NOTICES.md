# Data Notices & Attributions

Marginalia bundles the following third-party data. Application code is licensed
separately (see LICENSE).

## Scripture text

- **King James Version (KJV)** — Public Domain.
  Source: [aruljohn/Bible-kjv](https://github.com/aruljohn/Bible-kjv).
- **World English Bible, Classic Edition (WEB)** — Public Domain (dedicated to the
  public domain by the copyright holder, Michael Paul Johnson / eBible.org). The
  Classic edition uses "Yahweh" for the divine name in the Old Testament.
  Source: [eBible.org `eng-web`](https://ebible.org/eng-web/) verse-per-line distribution.

## Cross-references

- **Treasury of Scripture Knowledge**, as compiled and released by
  **OpenBible.info** — licensed **CC BY** (Creative Commons Attribution).
  Source: <https://www.openbible.info/labs/cross-references/>.
  "Cross-reference data from OpenBible.info, used under CC BY."

## Strong's numbers (KJV+)

- **KJV word→Strong's tagging** — from
  [kaiserlik/kjv](https://github.com/kaiserlik/kjv). KJV text is Public Domain;
  Strong's numbering is from Strong's Exhaustive Concordance (1890), Public Domain.
- **Strong's Hebrew & Greek dictionaries** (definitions) — from
  [OpenScriptures/strongs](https://github.com/openscriptures/strongs),
  licensed **CC BY-SA**. Derived from James Strong's 1890 concordance.
  "Strong's dictionary data from OpenScriptures, used under CC BY-SA."

## Reading schedule

- **The Bible Companion** — the daily reading plan compiled by **Robert Roberts**
  (1839–1898), Public Domain. The whole Bible in a year: Old Testament once, New
  Testament twice, in three daily portions.
  Chapter/verse table transcribed from
  [dawnchristadelphians.ca/companion](https://dawnchristadelphians.ca/companion/preface.html).
  Two transcription typos are corrected in `data/build-companion.mjs`.
